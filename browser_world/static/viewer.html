      How the pieces connect
      
    
      
      
      Booking rulesbooking.py
        
      Services, doctors, dates, slots, validation, bookings, reset.
      
      →
      
      Serverserver.py
        
      JSON API over the rules, one isolated session per worker.
      
      →
      
      Booking pageapp.html · app.js
        
      Three-step wizard running in real Chromium.
      
      →
      
      Observerobserver.py
        
      Reads four planes over Chrome DevTools Protocol.
      
      →
      
      Deltadelta.py
        
      What changed between two observations.
      
      →
      
      Next: recorder
        
      Saves before → action → after records for training.
